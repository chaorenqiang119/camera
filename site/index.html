SDK 头文件、库和驱动使用官方安装包。运行前关闭占用设备的 GalaxyView。

git clone https://github.com/chaorenqiang119/camera.git
cd camera

# 先安装官方 Galaxy SDK，再安装构建依赖
sudo apt-get update
sudo apt-get install -y build-essential cmake libopencv-dev

cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
./build/camera_demo --no-display --frames 100
git clone https://github.com/chaorenqiang119/camera.git

cmake -S . -B build -A x64 `

  -DGXIAPI_LIBRARY="C:/path/to/sdk/GxIAPI.lib" `

02 / ACQUISITION PIPELINE

一帧图像的完整路径。

  1. 01

    初始化与枚举

    初始化 SDK，保留原始设备序号，选择支持的相机。

    GXInitLib / GXOpenDeviceByIndex
  2. 02

    配置与开流

    连续采集、关闭触发，设置像素格式与 5 个缓存。

    GXStreamOn
  3. 03

    取帧与转换

    检查帧状态和大小，转换 Bayer 图像或复制 Mono8。

    GXDQBuf / DxRaw8toRGB24Ex
  4. 04

    归还与释放

    显示前归还帧；退出时停流、关设备并关闭 SDK。

    GXQBuf / GXStreamOff

统一的 rm_log 输出

时间、等级、线程、源文件、函数和行号，贯穿配置、FPS、超时与退出。异步队列容量 4096，单文件上限 5 MiB，保留 3 个轮转文件。

RM_LOG_INFO("Opened camera, SDK index={}", index);
RM_LOG_DEBUG("FPS={:.2f}", fps);
RM_LOG_ERROR("{} failed: status={}", op, status);

运行时调参

e / d
曝光 ±25 μs
a / q
增益 ±0.1
s / w
Gamma ±0.1
ESC
停止采集，释放资源

参数按节点范围和步长限幅，不支持的可选节点记录 WARN。
